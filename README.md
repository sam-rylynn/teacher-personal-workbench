# 教师个人工作台 · 首版框架

这是一个面向老师个人的工作台交互框架，用来验证以下核心产品链路：

- 电脑端统一管理学生档案、教学课表、事项和资料；
- 学生档案以成绩、排名变化、近期问题和家校协同为核心；
- Agent 只生成待确认变更，老师确认后才进入正式数据；
- 手机端只查看电脑发布的只读快照，不提供新增、编辑或删除入口。

当前页面内的学校、老师、学生、课表和记录均为虚构演示数据。

## 当前包含

- 今日工作台：下一节课、学生成绩与近期动态、收口事项；
- 教学安排：周课表、课次详情、课表导入确认流程；
- 学生档案：成绩与排名趋势、进退步动态、近期问题、家长沟通难度与辅助意愿阶梯；
- 事项中心：教学、学生、行政、论文任务；
- 资料与导入：文件卡片与 Agent 变更草稿；
- 发布到手机：内容选择、快照预览、发布完成和手机只读预览。

## 运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

检查构建：

```bash
npm run build
npm run lint
npm test
```

## 首版边界

这是一版可点击的交互框架，不代表以下底层能力已经完成：

- 本地 SQLite 或 IndexedDB 正式数据层；
- 照片 OCR 与 Excel 实际解析；
- Agent 真实连接、密钥保管和变更协议；
- 快照加密、Git 自动发布和手机配对；
- Windows/macOS 桌面安装与离线更新。

正式工程建议继续保持三层分离：标准核心代码、用户配置层、本地数据层。学生资料、附件、AI 密钥和 Git 写入凭据不得写入源码仓库。
