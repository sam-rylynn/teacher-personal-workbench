# 教师个人工作台

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

面向个人老师的本地优先开源工作台，支持 Windows 和 macOS。不是学校 SaaS，也不包含内置 AI。当前代码基于 `v0.5.0` 并包含后续审查修复；真实设备交付仍需按文档验收。

老师在电脑浏览器里维护学生档案、成绩、课表和事项。正式数据默认保存在当前电脑的当前浏览器中；产品本身不把这些数据同步给开发者。

## 当前能做什么

- 今日：查看下一节课、重点学生和待办事项；
- 学生：维护学生档案，按学科查看已确认成绩、排名变化、近期问题和家校沟通信息；
- 成绩导入：从 Excel 或其他表格复制 CSV/TSV 文本，先作为待确认记录导入，再编辑、确认或删除；
- 课表：维护单次课程和每周固定课程，导入表格文本，撤销临时调课或取消，并删除录错课程，再导出 `.ics` 日历文件；
- 事项：记录教学、学生、行政和论文任务，设置本地提醒；
- 资料：查看当前资料列表；
- 数据：导出完整 JSON 数据文件、从文件恢复，并保留本浏览器内最近 3 份自动备份；
- 手机查看：电脑生成专用只读文件，老师把文件传到自己的手机后手动导入；
- 手机速记：在手机浏览器中单独记录，复制速记内容后再回到电脑导入为待办事项。

当前演示环境中的学校、老师、学生、课表和记录均为虚构数据。交付前应清除演示数据，再由老师本人决定导入哪些真实资料。

## 数据与设备边界

### 电脑正式数据

学生、成绩、课表、事项、资料索引和自动备份保存在当前浏览器站点存储中。公开、克隆或 Fork 本仓库不会读取或上传这些内容，也不会让它们自动出现在另一台电脑或另一种浏览器中。

日常使用应保持同一个浏览器和访问地址。改变端口、域名，或把 `localhost` 换成 `127.0.0.1`，都会打开另一份独立的浏览器数据空间；原有数据仍在原地址。确需换地址时，先在原地址导出完整备份，再到新地址恢复。

浏览器站点数据被清除、浏览器配置损坏或设备丢失时，本机自动备份也会一起丢失。因此应定期在“数据与备份”中导出完整 JSON 文件，并把文件保存在老师自己控制的安全位置。

### 手机查看文件

手机端不读取电脑浏览器的数据，也没有自动同步。正确流程是：

1. 在电脑点击“生成手机查看文件”；
2. 将下载的文件通过老师自己控制的方式传到手机；
3. 在手机可访问的工作台页面打开 `?mode=mobile`；
4. 选择“导入新内容”，手动导入该文件。

手机文件只包含查看页所需摘要，不是完整桌面备份。学生姓名和摘要仍可能属于个人信息，不应放入公共仓库或公共网盘。重新导入只会更新手机查看内容，不能修改电脑中的正式数据。

电脑上的 `localhost` 地址不能直接在另一台手机上使用。首次部署还需要确认一个手机实际可访问的页面入口；仓库本身不附带云托管或跨设备同步服务。

### 手机速记

手机速记保存在手机当前浏览器中，与手机只读摘要和电脑正式工作区相互独立。它不会自动进入电脑、不会修改学生或课表，也不包含在电脑自动备份中。需要在手机复制速记内容，再在电脑“数据与备份”中粘贴导入。清除手机浏览器数据前应先完成复制或导入。

## Agent 与 AI 边界

本工作台没有内置 AI、模型账号、API 密钥管理或自动调用外部模型的能力。

老师可以在工作台之外使用自己的 Agent，协助克隆仓库、本地部署、启动排障、代码微调，或把老师主动选择的文件整理成可导入内容。Agent 是外部工具，不会自动读取工作台本地数据。老师一旦把真实资料交给外部 Agent 或 AI，数据就可能离开本机，应自行确认资料范围、服务条款和必要性。

## 安装与启动

需要 Node.js `>= 22.13.0`。第一次安装在项目目录执行：

```bash
git clone https://github.com/sam-rylynn/teacher-personal-workbench.git
cd teacher-personal-workbench
npm ci
```

日常启动可以执行：

```bash
npm run launch
```

也可以在依赖安装完成后使用：

- Windows：双击 `启动工作台.bat`；
- macOS：双击 `启动工作台.command`。

终端保持运行期间，浏览器打开 `http://localhost:3002/`。停止终端进程后，本地页面也会停止服务。

`npm run launch` 只接受本机连接；首次运行或 Agent 修改源码后，会自动重新生成运行文件，代码没有变化时直接启动。更新依赖清单后需要先重新执行 `npm ci`。启动器会检查端口是否被占用；如果工作台已经运行，直接回到同一地址使用即可。

开发调试使用：

```bash
npm run dev
```

执行候选版检查：

```bash
npm run verify
```

## 当前不包含

- 照片 OCR、直接读取 `.xlsx` 文件或自动识别拍照课表；
- 云数据库、账号体系、多人协作或跨设备自动同步；
- 手机直接编辑学生、成绩、课表或桌面事项；
- 内置 Agent、内置 AI、模型密钥托管或自动生成正式判断；
- 自动云部署、手机配对、短信、微信或云推送；
- 持续维护、自动升级和设备故障恢复服务。

真实学生资料、完整备份、手机查看文件、外部 AI 密钥和 Git 写入凭据都不得写入源码仓库。
